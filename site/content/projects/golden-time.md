## 왜 만들었나: 해결하려던 문제

전북의 소아과는 전주에 몰려 있어서, 군 지역에서 아이가 아프면 대부분 무조건 전주로 갑니다.
하지만 사는 위치에 따라서는 충남·전남·경남 등 **다른 도의 병원이 실제로 더 빨리 도착**하는 경우가 있습니다.
행정구역이 아니라 **실제 도착 시간**을 기준으로, 지금 위치에서 가장 빨리 갈 수 있는 소아과를 알려 주는 것이 목표였습니다.

## 나의 역할과 기여 범위

팀 작업은 화면(프론트엔드), 지도 표시, 발표 준비를 나눠 맡았고, 저는 **기획과 백엔드**를 담당했습니다.

**내가 직접 한 일**

- 서비스 방향 기획: "행정구역이 아니라 도착 시간으로 의료권을 다시 그린다"는 핵심 메시지 정리, 프로젝트 문서 갱신
- 프로젝트 초기 세팅과 환경 변수 관리(`.env.local.example`) 정리
- **Tmap 경로안내 API 연동** 코드(`lib/tmap.ts`) 작성
- **건강보험심사평가원 병원정보 API**로 소아과 목록을 수집하고 데이터베이스(Supabase)에 저장하는 `/api/sync` 기능 작성
- 전북 밖 병원도 찾을 수 있도록 수집 기준 지역에 경남 함양·거창, 충북 영동·옥천, 전남 담양·장성 추가
- 발표자료용 근거 자료 정리(실제 API 응답 수치, 기술 설명, 예상 질문 답변)

**팀원이 맡은 일:** 메인 화면과 지도 UI, 응급실·의료장비 정보 화면, 발표 슬라이드 제작

## 진행 과정과 선택 이유

1. **기획:** 핵심 기능을 "현재 위치 → 가장 빨리 도착하는 소아과"로 좁혔습니다. 로그인·즐겨찾기·예약 같은 기능은 2일 안에 핵심 메시지에 집중하기 위해 일부러 빼기로 했습니다.
2. **데이터 수집:** 병원 목록은 정부 공공데이터(심평원)를 하루 1회만 받아 데이터베이스에 저장했습니다. 요청마다 공공데이터를 부르면 느리고 호출 한도에 걸리기 때문입니다.
3. **도착 시간 계산:** 단순 직선거리가 아니라 **실시간 교통 정보를 반영한 자동차 소요시간**이 필요해서, 실시간 정체를 반영하는 옵션(`trafficInfo`)이 있는 **Tmap 경로안내 API**를 선택했습니다.
4. **호출 수 줄이기:** 경로 API는 호출할수록 느려지고 비용이 들기 때문에, 직선거리로 가까운 후보 8곳만 먼저 고르고 그 8곳만 동시에 경로 API를 호출했습니다. 같은 위치에서 3분 안에 다시 요청하면 이전 결과를 재사용했습니다.
5. **배포:** 별도 서버 없이 Next.js 하나로 화면과 API를 함께 만들고 **Vercel**에 배포했습니다. 2일이라는 짧은 시간 안에 서버를 따로 운영하지 않아도 되기 때문입니다.

**사용 기술:** Next.js · TypeScript · Tailwind CSS · Supabase(PostgreSQL) · Tmap 경로안내 API · 건강보험심사평가원 병원정보서비스 · Vercel

## 결과물

![골든타임 시연 화면: 왼쪽에는 현재 위치 기준 가장 가까운 소아 진료 가능 병원과 도착 예상 시간 목록이, 오른쪽 지도에는 전북과 주변 지역의 병원 위치가 표시되어 있다](/images/projects/golden-time-map.jpg)

*그림: 대회 당시 시연 화면. 현재 위치를 기준으로 도착 시간이 짧은 병원 순서로 목록과 지도에 표시합니다.*

발표 준비 중 실제 서비스 API를 장수군 좌표로 호출해 확인한 결과, **전북 안의 병원(37.1km, 42분)과 경남 함양의 소아청소년과(48.8km, 44분)의 도착 시간 차이가 2분밖에 나지 않았습니다.**
행정구역 안에서만 찾으면 놓치는 대안이 실제로 있다는 것을 숫자로 확인했고, 이 결과를 발표 자료에 활용했습니다. 팀은 이 프로젝트로 **우수상**을 받았습니다.

## 배운 점과 한계, 다음 개선 방향

**배운 점**

- 외부 API를 쓸 때는 호출 횟수와 응답 속도를 먼저 설계해야 실제로 쓸 수 있는 서비스가 된다는 것
- API 키를 코드와 분리해 환경 변수로 관리하고, 실수로 Git에 올라가지 않게 해야 한다는 것

**한계**

- 사용한 병원 목록 API에는 요일별 진료시간 정보가 없어서, 진료가 끝난 병원도 목록에 함께 나올 수 있습니다.
- 대회 후 데이터 적재를 멈춰서 병원 정보가 갱신되지 않습니다.

**다음 개선 방향**

- 진료시간을 제공하는 다른 공공데이터 API를 찾아 연결해 "지금 진료 중인 병원"만 걸러 보기
- 데이터 적재를 자동 예약 실행으로 바꿔 정보가 계속 최신 상태를 유지하게 하기
- [소개](/about/) 페이지의 학습 계획대로, 이 프로젝트 코드에서 API 키 관리와 입력값 검증 부분을 보안 관점으로 다시 점검하기
