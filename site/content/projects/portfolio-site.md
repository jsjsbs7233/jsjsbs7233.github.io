## 목적

본인을 소개하는 웹사이트를 직접 만들고, **main 브랜치에 push하면 자동으로 빌드·배포되는 흐름**을 구성해 보는 것이 목표였습니다.
화면만 만드는 것이 아니라 모바일, 키보드, 화면 확대처럼 여러 환경에서도 실제로 쓸 수 있는 사이트를 만드는 데 집중했습니다.

## 진행 과정과 선택 이유

1. **테마 선택:** Hugo 테마 중 [hugo-coder](https://github.com/luizdepra/hugo-coder)를 골랐습니다. 구성이 단순해 예시 콘텐츠를 정리하기 쉽고, 추가 패키지 설치(npm) 없이 빌드되며, 모바일 메뉴와 다크 모드가 기본으로 들어 있기 때문입니다.
2. **배포 구성:** 수업에서 제공한 준비 스크립트로 `site` 폴더와 GitHub Actions 워크플로를 만들고, 저장소 설정에서 Pages 배포 방식을 GitHub Actions로 지정했습니다.
3. **예시 콘텐츠 정리:** 테마에 들어 있던 가상 인물(John Doe), 포르투갈어 번역, 예시 블로그 글과 이미지를 지우고 한국어 단일 언어로 바꿨습니다.
4. **콘텐츠 작성:** 소개 페이지와 해커톤 활동 페이지를 작성했습니다.
5. **점검과 개선:** 키보드와 화면 확대로 직접 사용해 보며 문제를 찾아 고쳤습니다(아래 참고).

## 점검하며 고친 문제

| 발견한 문제 | 원인 | 수정 내용 |
|---|---|---|
| 브라우저를 200%로 확대하면 Tab 키로 메뉴 버튼에 갈 수 없어 메뉴를 열 수 없음 | 좁은 화면에서 메뉴를 여닫는 체크박스가 `visibility: hidden`이라 키보드 초점을 받지 못함 | 체크박스를 화면에서는 숨기되 초점은 받을 수 있게 바꾸고, 초점이 오면 메뉴 아이콘에 테두리가 보이게 함 |
| 다크 모드 버튼이 키보드로 선택되지 않고 화면 낭독기에서 이름이 없음 | 주소가 없는 링크 태그에 아이콘만 들어 있음 | 버튼 역할과 이름을 붙이고 Enter·Space 키로도 동작하게 함 |
| 본문의 넓은 표가 휴대폰 화면에서 페이지 밖으로 넘칠 수 있음 | 표의 폭이 화면 폭보다 넓음 | 표 영역 안에서만 가로 스크롤되게 하고 긴 URL은 줄바꿈되게 함 |
